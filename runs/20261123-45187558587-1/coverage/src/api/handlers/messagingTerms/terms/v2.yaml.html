# `version` is what a participant agrees to: raise it (in a new file, v3.yaml) when the meaning
# changes, and everybody is asked again before their next message. `revision` is for fixes that
# change no meaning (a typo, a clearer word): raise it here, nobody is asked again.
# `terms.test.ts` pins the text of every version and revision; changing it without raising one of
# them fails the test. Never delete an older file: it is the record of what people agreed to.
